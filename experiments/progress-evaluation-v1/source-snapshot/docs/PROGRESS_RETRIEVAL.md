## Trace contract

`decision.repair` records variant/stage/trigger, no-information count, repeated-pose evidence and complete bounded history, novel observed IDs, candidate/raw budgets, executed source and explicit fallback allowance/activity. Labeled cues include their query indices and actual vectors. Attempts are lightweight route-index/label/p references; the actual per-cue core route and original IDs occur once in decision.route. `decision.queries` contains actual effective cues; `decision.route` remains the actual numerical route list. A full-bank graph recovery read has no invented numerical routes.

Each new wire route references snapshot_id: SHA256 of canonical sorted compact JSON of its layout. The bank preserves source_snapshot_label because the numerical core caller label is not unique across index builds. The episode-level routing_snapshots bank stores original index order and true core node spans once per snapshot, with start-inclusive/stop-exclusive logical ranges and chunk/depth. Route use/decision-source labels remain explicit. In-memory reader returns preserve the complete info; serialized frames deduplicate it. Logical0 is the mandatory sink; logical1 maps to `index_fact_ids[0]`. These are inspection copies; mutation cannot change the core. Historical traces are not retroactively decorated. Oversized pre-compact diagnostic/development v1 artifacts are preserved as failed-size versions. Compact development v2 preserved the policy but exposed an inherited baseline header incorrectly declaring0 mask bytes; v3 corrects it to512 for every condition, since every injected reader receives the mask. New serialized artifacts must stay below128MiB expanded and record actual expanded bytes; the inspector limit is unchanged.

Record source/lock/version hashes and all official partial observations, actions, rewards, terminations and failures. Do not tune after fresh evaluation. Official success, sparse numerical correctness, useful cue recovery and graph-assisted completion are different claims. This adapter does not establish learned cognition, dreaming, novelty, speed or general navigation competence.
