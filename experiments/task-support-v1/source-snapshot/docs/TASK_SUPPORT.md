# Task-useful support recovery

Implementation protocol, 13 November 2026. This protocol is fixed before the fresh comparison.

## Diagnosis and hypothesis

Post-hoc intervention on the exposed parent-policy seed19001–19004 traces uses only observed prefixes. Re-running the same symbolic planner with all observed heads, active heads, then packed returns localizes stalled decisions. These are same-state interventions, not alternate-episode outcomes or an independent planner proof. No hidden MiniGrid grid or future facts enter this analysis.

Hypothesis: bounded workspace admission can break an already-observed route. Returning a relevant landmark without its path is insufficient. Compact path/prerequisite bundles and explicit observed-graph recovery may restore useful evidence at the same64-fact active capacity. Any benefit can come from graph search and the changed interface; it is not automatically a ZHA benefit.

## Declared interventions

- Parent: unchanged fitted ZHA persistent reader.
- Compact: same recovery backend, compact path/prerequisite/cue bundles; optional one-hop halos omitted.
- Connected ZHA: compact packing plus explicit cold observed-head graph support when no admissible progress bundle remains. Seeds must come from active or actually routed sources. Connecting path evidence may be outside the routed set and is explicitly disclosed.
- Connected exact: same connector using the exactly scored bank as seed candidates.
- Connected graph: same connector and all observed-head seeds, with numerical archive retrieval disabled. This isolates the non-ZHA contribution.

All readers use the same symbolic planner, current observations and known-only coverage. Current observations count toward64 active slots; at most16 newly admitted cold facts per read. Temporary routed-candidate decoding and connector full-head materialisation are extra work outside that active capacity and are separately counted. The canonical archive, keys and head cache can grow; no total-memory or sublinear-search claim is made.

Connector gates use declared observed progress: normal archive recovery scheduling or at least two stable-coverage reads with no complete non-cue bundle. A core budget failure never silently invokes a graph fallback. Complete bundles preserve their seed, recorded path edges, matching key and cue; oversized/missing bundles are explicitly rejected. Optional halos are omitted because known-only coverage already suppresses false unexplored frontiers. Corrections invalidate cached heads by source version. The cache holds immutable facts; lists returned to callers are owned copies.

## Evaluation

Development uses only the already-exposed cases19001–19004. Freeze source, protocol and checkpoints before running all five conditions on four official environments with new seeds23001–23006, an external256-action cap and64 active slots. No result-based tuning or cherry-picked task subsets. Keep every failure. Different RNG seeds do not guarantee distinct geometry; report per-task cases and avoid significance claims.

Measure solved cases, actions, scan-stall decisions, originals, hot/cold and graph work, archive materialisation, peak serialized cached payload bytes and timing. Cache on/off behavior parity is required; runtime speed is a separate measurement and must include construction/materialisation. Reuse all numerical core gates. Independently replay official actions, source/correction chains, capacities, connector seed origins, actual path edges and selected numerical routes. The independent auditor must not import the production reader, features, packing or planner.

## Boundaries

This implements task-aware observed-evidence recovery. It does not train a new salience model, implement biological dreaming, certify semantic correctness or establish a novel retrieval algorithm. Offline routing replay remains separately evaluated; its lower KL is not claimed to improve planning. Learned task-level replay, rare-memory protection, incremental numerical tree updates and supported GPU/model conversion remain later gates.
