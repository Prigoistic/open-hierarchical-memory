# Security and scope

This is a local research reference. The dashboard binds to loopback by default and can start local solver jobs and write archives. It has no authentication and is not designed for public network exposure. Do not expose its port through a public tunnel as a hosted service.

Numerical APIs enforce their declared input/resource contracts; those limits are not operating-system isolation. A bounded active workspace does not bound the canonical archive or total process memory. SQLite persistence is a single-writer POSIX research backend.

Use trusted experiment artifacts. Loaders apply size and integrity checks, but checksums are not signatures or a sandbox. Never load arbitrary Python checkpoints or execute unknown source snapshots. No runtime credential or external model API is required for the local maze/dashboard demonstrations.

For a suspected vulnerability, use GitHub's private vulnerability reporting on the repository if enabled. If that channel is unavailable, open a minimal issue requesting private contact without including exploit details or sensitive data. No response-time or production-support commitment is implied.
