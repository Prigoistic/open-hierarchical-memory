## Bounded stages

All changes use observed canonical-payload novelty and a 24-pose/orientation window. A previously seen door state returning is not new information merely because it gets a new version. Every correction still updates canonical heads/indexes. Novelty storage is bounded by the existing 8192-record archive limit.

- Ordinary source reads use existing local/mission/sample cues.
- After 8 no-information reads with repeated pose, add four directional free-cell cues. They are continuous position features displaced 8 cells east/south/west/north, with declared floor channels. They contain no hidden target or answer label.
- After 16 no-information reads, raise the source candidate budget from 96 to 192. The returned planner support remains ≤96. Actual adaptive p attempts and all original/summary/rerank work remain recorded.
- `progress_zha` and `progress_exact` use explicit observed-graph recovery after 24 repeated-stall reads, or a hard 48 no-information reads without repetition. Graph mode continues until new observed canonical information; it is an ordinary full-observed graph source, not a ZHA success. `cues_zha` and `cues_exact` disable that fallback to isolate actual requery/widening contributions.

The matched controls are old `bundle_zha`, `bundle_exact`, and ordinary `graph`, with identical masks/closure/packing/planner. Every graph recovery, history check, novelty lookup, extra query, candidate read, span export and source operation is counted. Same output capacity does not mean equal compute.

## Trace contract

`decision.repair` records variant/stage/trigger, no-information count, repeated-pose evidence and complete bounded history, novel observed IDs, candidate/raw budgets, executed source and explicit fallback allowance/activity. Labeled cues include their query indices and actual vectors. Attempts are lightweight route-index/label/p references. `decision.queries` contains actual effective cues. Reader returns contain actual numerical routes; serialized `decision.route` contains ordered references to the exact per-cue core events and original IDs in `routing_events`. A full-bank graph recovery read has no invented numerical routes.

Each new numerical wire route is an ordered route_ref into the episode.routing_events bank, content-addressed by SHA256 of canonical actual route JSON. Repeated calls still execute and their per-read work is counted; only identical inspection records are deduplicated. The event references snapshot_id: SHA256 of canonical sorted compact JSON of its layout. The bank preserves source_snapshot_label because the numerical core caller label is not unique across index builds. The episode-level routing_snapshots bank stores original index order and true core node spans once per snapshot, with start-inclusive/stop-exclusive logical ranges and chunk/depth. Route use/decision-source labels remain explicit. In-memory reader returns preserve the complete info; serialized frames deduplicate it. Logical 0 is the mandatory sink; logical 1 maps to `index_fact_ids[0]`. These are inspection copies; mutation cannot change the core. Historical traces are not retroactively decorated. Oversized pre-compact diagnostic/development v1 artifacts are preserved as failed-size versions. Compact development v2 preserved the policy but exposed an inherited baseline header incorrectly declaring 0 mask bytes; v3 corrects it to 512 for every condition, since every injected reader receives the mask. New serialized artifacts must stay below 128MiB expanded and record actual expanded bytes; the inspector limit is unchanged.

Record source/lock/version hashes and all official partial observations, actions, rewards, terminations and failures. Do not tune after fresh evaluation. Official success, sparse numerical correctness, useful cue recovery and graph-assisted completion are different claims. This adapter does not establish learned cognition, dreaming, novelty, speed or general navigation competence.

The first 3001–3006 evaluation attempt is retained as an incomplete transport-failure version: one long no-recovery control exceeded 128MiB despite layout deduplication. The decision policy was already frozen. A content-addressed exact route-event bank repairs serialization only; the SAME cohort is re-executed with policy-byte equality attested. This is not a new untouched cohort or a tuned policy. All overlap actions/observations/selected IDs must agree, and no failed case is dropped.
